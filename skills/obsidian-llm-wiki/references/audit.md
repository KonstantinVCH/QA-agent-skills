# Режим audit — проверить страницу против её источников

Запускать, когда есть сомнения в точности конкретной страницы.

## Процесс

1. Прочитать указанную страницу целиком.
2. Выписать все фактические утверждения (числа, имена, поведение, причины).
3. Для каждого утверждения:
   - найти источник в `sources:` frontmatter страницы;
   - прочитать источник (`obsidian_get_file_contents(источник)`);
   - пометить: ✅ подтверждено / ⚠️ не найдено в источнике / ❌ противоречит источнику.
4. Выдать отчёт в чат. **Страницу не редактировать без явного «да» пользователя.**
5. Пользователь согласен — исправить противоречия, к непроверяемым выводам добавить
   `[inferred]`. Правку записать в `wiki/log.md` (операция `audit`).

## Формат отчёта

```
АУДИТ · [[{страница}]]
Источников в sources: {n}, утверждений: {n}

✅ {n}   ⚠️ {n}   ❌ {n}

❌ 1. «{утверждение}»
      источник [[sources/...]] говорит: «{цитата}»
⚠️ 2. «{утверждение}» — в источниках не найдено; кандидат в [inferred] или HYPOTHESIS
...
```

Страница с `reviewed: true` — противоречие всё равно показать, но исправление только
дописыванием (пометка рядом с утверждением), без переписывания текста человека.
