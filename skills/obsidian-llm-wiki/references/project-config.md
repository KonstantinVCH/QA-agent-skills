# Настройка под проект

Заполните один раз. Незаполненное скилл берёт по умолчанию (раскладка из `SKILL.md`)
или спрашивает у пользователя.

## Vault и доступ

| Параметр | По умолчанию | Ваше значение |
|---|---|---|
| Путь к vault | переменная `OBSIDIAN_VAULT` | `{путь, например ~/notes}` |
| Способ доступа | MCP → Local REST API → файлы | `{только MCP / только чтение файлов / …}` |
| Local REST API | `https://127.0.0.1:27124` | `{хост:порт}` |
| Ключ API плагина | переменная `OBSIDIAN_API_KEY` | из настроек плагина Local REST API; в файлы не вставлять |
| Запись в файлы напрямую разрешена | да | `{нет, если индекс или ссылки ведёт плагин}` |

## Раскладка

| Что | По умолчанию | Ваше значение |
|---|---|---|
| Точка входа | `wiki/overview.md` | `{путь}` |
| Каталог страниц | `wiki/index.md` | `{путь}` |
| Журнал | `wiki/log.md` | `{путь}` |
| Entity | `wiki/entities/` | `{путь}` |
| Concept | `wiki/concepts/` | `{путь}` |
| Source по задачам | `sources/{topic}--summary.md` | `{шаблон пути}` |
| Lessons | `lessons/` | `{путь}` |
| Правила для LLM (schema) | `wiki/schema/config.md` | `{путь или «нет»}` |
| Рабочие папки сессий | `{topic}/` (например `PROJ-123/`) | `{шаблон}` |
| Папка шаблонов страниц | `templates/` | `{путь}` — исключать из lint |

Файлы, которые **нельзя читать целиком** (только поиском): `wiki/index.md`
и `{другие большие справочники}`. Отметка размера помогает: файл больше ~30 тыс.
символов — только поиск.

Кто ведёт индекс: `агент на каждом ingest` (по умолчанию) или `{плагин}` — тогда шаг
«Индекс» в ingest пропускается.
