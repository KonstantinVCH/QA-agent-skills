# Jaeger как MCP-сервер (необязательно)

`scripts/jaeger_trace.py` работает сразу: только стандартная библиотека, ни установки, ни
конфигов. MCP — удобная обёртка, если хочется спрашивать словами («найди ошибки в
order-service за час»), а не командой.

`scripts/jaeger_mcp.py` — MCP-сервер по stdio с инструментами `jaeger_services`,
`jaeger_operations`, `jaeger_find_traces`, `jaeger_get_trace`, `jaeger_analyze_trace`
(ошибки, медленные спаны > 200 мс, корневой спан), `jaeger_find_errors`. Адрес берёт из
`JAEGER_URL`.

## Подключение к Claude Code — скриптом

Просят настроить MCP — не диктуй шаги, запусти скрипт (он подставит верные пути сам):
```bash
export JAEGER_URL=https://{JAEGER_HOST}
python scripts/setup_jaeger_mcp.py          # проверки и план, ничего не меняя
python scripts/setup_jaeger_mcp.py --apply  # записать в ~/.claude.json (с бэкапом)
```
Скрипт проверяет Python ≥ 3.10, наличие `mcp` и `httpx`, файл сервера, доступность Jaeger
(и отличает «нет сети/VPN» от «нет MCP»), показывает готовый блок конфига и предупреждает, если
сервер с таким именем уже описан. Путь интерпретатора берётся из `sys.executable`. Перед записью
кладётся бэкап `~/.claude.json.bak-<дата>`. После `--apply` скажи человеку про перезапуск
сессии: конфиг читается при старте.

Скилл сам MCP подключить не может — это конфиг клиента, его правит скрипт с согласия человека.

## Вручную — четыре места, где обычно спотыкаются

1. **Зависимости и версия.** `pip install mcp httpx`; пакету `mcp` нужен Python ≥ 3.10.
2. **Полный путь к интерпретатору.** На Windows `"command": "python"` резолвится не всегда —
   пиши путь целиком (`where python` / `which python3` покажет свой).
3. **Тот самый файл конфига.** Claude Code читает пользовательские MCP-серверы из
   `~/.claude.json` (ключ `mcpServers` верхнего уровня); проектные — из `.mcp.json` в корне
   проекта. У Claude Desktop свой файл — `claude_desktop_config.json`.
4. **Перезапуск.** Сервер поднимается при старте сессии, на лету конфиг не перечитывается.

```json
"jaeger": {
  "type": "stdio",
  "command": "<полный путь к python>",
  "args": ["<путь к скиллу>/scripts/jaeger_mcp.py"],
  "env": {"JAEGER_URL": "https://{JAEGER_HOST}"}
}
```

Проверка, что взлетело: спросить «какие сервисы есть в Jaeger» — должен вернуться список.
Пусто или таймаут → сначала `curl "$JAEGER_URL/api/services"` (ожидается 200): если и он молчит,
дело в сети/VPN, а не в MCP.
