# Внутренний критик: нейропаттерны

Отдельный редакторский проход по готовому тексту — баг-репорту, отчёту о тестировании, вопросу
аналитику, ответу в чат. Цель — вычистить обороты, по которым текст опознаётся как «машинный» и
из-за которых читатель перестаёт верить фактам внутри.

## Зачем отдельным проходом

Черновик написан — работа не закончена. Перечитай текст ещё раз, уже не как автор, а как
придирчивый читатель, которому этот отчёт свалился в переписку. Совмещать проход с написанием
нельзя: автор своих же формул не видит.

Если в сессии установлен скилл редактуры русского текста (например, `redaktura` с его разбором
нейротекста) — прогони готовый текст через его проходы. Нет такого скилла — работай по списку
ниже.

## Что ищем

| Паттерн | Как выглядит в QA-тексте | Чем заменить |
|---|---|---|
| Антитеза «не X, а Y» | «Не дефект кода, а особенность данных» | Прямое утверждение с фактом: «Причина — пустая `orders.delivery_info`» |
| Оценочный анонс | «Важный нюанс», «Честная оговорка», «Хорошая новость» | Удалить ярлык, оставить факт. Нужна навигация — сделать заголовок |
| Дробь многозначительности | «Коротко. Точно. По делу.» | Одно нормальное предложение с причиной |
| Правило трёх | «быстро, стабильно и предсказуемо» | Одно точное слово |
| Дежурная связка | «Стоит отметить», «Важно понимать», «Кроме того» | Выкинуть, начать предложение с факта |
| Хеджирование | «может приводить», «как правило», «в определённой степени» | Либо утверждать и отвечать за слова, либо один раз прямо написать «не проверено» |
| Формульный финал | «В заключение», «В конечном итоге всё сводится к» | Последняя строка — действие или факт |
| Канцелярит и кальки | «является», «данный», «осуществляет проверку» | Живой глагол: «проверяет» |
| Декор | эмодзи перед каждым пунктом, жирные первые слова буллетов | Форматирование только там, где оно помогает читать |
| Равномерность | все абзацы одной длины, каждый закрыт мини-выводом | Чередовать: где-то густо фактами, где-то одна фраза |

## Запрещённые обороты — всегда

«важно отметить» · «в данном контексте» · «динамично» · «успешно протестировано» ·
«в заключение» · «стоит упомянуть» · «это про…» / «это не про…»

«Успешно протестировано» запрещено отдельной строкой: это оценка вместо результата. Пиши, что
именно вернул сервис и с чем это сравнили.

## Процедура

1. Прочитай текст вслух. Споткнулся — переписывай это место, а не полируй.
2. Прочитай подряд первые слова всех абзацев. Два одинаковых захода — один переписать.
3. Посчитай риторические антитезы. В тексте на один экран — ноль или одна.
4. По списку запрещённых оборотов пройди поиском, а не глазами.
5. Каждое найденное переписывай, а не смягчай. «Практически всегда» вместо «всегда» — то же
   самое место, только трусливее.

## Чего критик НЕ трогает

Длинное тире, кавычки-ёлочки, букву «ё», точные тексты ошибок, числа, единицы измерения, имена
методов, названия полей, коды ответов, traceId и ссылки. Фактические отрицания — тоже: «сервис
не хранит пароли» и «путь оплаты картой не проверялся» — это факты, а не риторические антитезы.
Сокращать и смягчать их запрещено: искажение смысла дороже любой экономии слов.

## Куда девать результат

Результат работы критика в текст не попадает. Это рабочая правка, а не раздел документа.
