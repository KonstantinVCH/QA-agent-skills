# Настройка под проект — шаблон

Скилл написан без привязки к конкретной компании. Всё, что зависит от вашего окружения, собрано
здесь. Заполни шаблон один раз (или скопируй его в базу знаний проекта и держи там) — тогда агент
не будет угадывать адреса, имена сервисов и соглашения команды.

Значения в `{ФИГУРНЫХ_СКОБКАХ}` — плейсхолдеры. Секреты сюда не пиши: только имена переменных
окружения, где они лежат.

---

## 1. Системы и доступы

| Система | Адрес | Переменные окружения | Где взять доступ |
|---|---|---|---|
| Трекер задач (Jira) | `{JIRA_URL}` | `JIRA_URL`, `JIRA_TOKEN` | профиль Jira → Personal Access Tokens |
| Вики (Confluence) | `{CONFLUENCE_URL}` | `CONFLUENCE_URL`, `CONFLUENCE_TOKEN` | профиль Confluence → Personal Access Tokens |
| Git-хостинг (Bitbucket Server / GitHub / GitLab) | `{BITBUCKET_URL}` | `BITBUCKET_URL`, `BITBUCKET_TOKEN` | профиль → HTTP access tokens (права на чтение репозиториев) |
| Трейсинг (Jaeger) | `{JAEGER_URL}` | — / `JAEGER_TOKEN` | обычно открыт внутри сети |
| Логи (OpenSearch / Kibana) | `{OPENSEARCH_URL}` | — | SSO / у DevOps |
| Брокер сообщений (RabbitMQ management) | `{RABBITMQ_URL}` | `RABBITMQ_USER`, `RABBITMQ_PASSWORD` | у DevOps |
| БД стенда (PostgreSQL) | `{DB_HOST}:{DB_PORT}` | `DB_DSN` (запись), MCP postgres (чтение) | у DevOps / в секретах стенда |
| Тест-менеджмент (Allure TestOps) | `{ALLURE_URL}` | `ALLURE_TOKEN` | профиль Allure → API tokens |
| Моки (WireMock) | `{WIREMOCK_URL}` | — | — |
| CI/CD (Bamboo / Jenkins / GitLab CI) | `{BAMBOO_URL}` | `BAMBOO_TOKEN` | профиль → Personal Access Tokens |
| База знаний (Obsidian, опционально) | `{KNOWLEDGE_BASE_PATH}` | `QA_KB_ROOT` | локальный клон репозитория базы |

Способ доступа к каждой системе выбирай по наличию:

1. MCP-сервер, если подключён (например, публичный `mcp-atlassian` для Jira и Confluence,
   MCP для PostgreSQL, Jaeger, Allure TestOps).
2. REST через `curl -fsSL` с токеном из переменной окружения.
3. Нет ни того, ни другого — остановись и попроси человека дать доступ. Не подбирай учётные данные.
