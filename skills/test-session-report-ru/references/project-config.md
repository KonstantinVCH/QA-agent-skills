# Настройки проекта

Заполни один раз под свою команду. Секреты (токены, пароли) сюда НЕ писать.

## Куда пишется отчёт

- Основной отчёт: `{подзадача «Тестирование» / комментарий в задаче / страница Confluence}`
- Короткая сводка: `{комментарий в родительской задаче / канал команды}`
- Чат команды для ссылки на тред: `{Slack / Mattermost / Telegram, ссылка на канал}`

## Системы и шаблоны ссылок

| Что | Значение |
|---|---|
| Трекер | `{JIRA_URL}`, ключ проекта `{PROJ}` |
| Git-хостинг, коммит | `{BITBUCKET_URL}/projects/{PROJECT}/repos/{repo}/commits/{hash}` (GitLab: `{GITLAB_URL}/{group}/{repo}/-/commit/{hash}`, GitHub: `https://github.com/{owner}/{repo}/commit/{hash}`) |
| Трейс на спан | `{JAEGER_URL}/trace/{traceId}?uiFind={spanId}` |
| Логи | `{OPENSEARCH_URL}` (Kibana / OpenSearch Dashboards) |
| Моки | `{WIREMOCK_URL}` |
| Стенды | `{STAND}` — список и как их называть в отчёте |

## Соглашения команды

- Значки итога: `(/)` `(x)` `(!)` `(?)` в Jira; ✅ ❌ ⚠️ ⏳ в Markdown — или свои, если приняты
- Словарь терминов команды (как называть сущности простыми словами): `{…}`
- Что считается «стенд чистый» после сессии: `{снимок моков, откат тестовых данных, возврат конфигов}`
- Где лежат коллекции запросов и тест-кейсы (для разбора «нет данных»): `{…}`
